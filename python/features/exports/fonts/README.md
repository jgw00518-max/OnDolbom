# PDF 한글 폰트

Nanum Gothic Regular / Bold 원본을 포함한다. 서버의 OS별 폰트 설치 없이 PDF에 필요한 글리프를 임베딩한다.

- 원본: https://github.com/google/fonts/tree/main/ofl/nanumgothic
- 다운로드: 2026-10-27
- 라이선스: SIL Open Font License 1.1, 동봉한 `OFL.txt` 참고
- 폰트 파일을 수정하지 않았으며 서비스 배포 시 폰트와 라이선스를 함께 포함해야 한다.

이모지 등 폰트에 없는 글리프는 PDF에서 `[U+XXXX]`로 표시하며 안내를 덧붙인다.
