# 개인 프로필 조회·수정

개인 설정에서 현재 계정의 이름·이메일·전화번호를 조회하고 **프로필 수정**으로 이동한다.

- 수정 가능: 이름(필수, 1~20자), 전화번호(필수).
- 전화번호: `01012345678`, `010-1234-5678` 두 형식을 허용하며 서버에서 `010-1234-5678`로 통일한다.
- 이메일은 조회 전용이다. Firebase 로그인 이메일·비밀번호·공간별 역할은 변경하지 않는다.
- `GET /auth/me`는 기존 조회 API를 사용한다.
- `PUT /auth/profile` 본문은 `name`, `phone`만 허용한다. 수정 대상은 Firebase ID 토큰의 UID로 서버에서 결정한다.
- 최초 등록인 `POST /auth/profile`과 구분한다. 미등록 사용자는 수정 API에서 새로 생성하지 않는다.
- 저장 성공 시 프로필을 다시 조회해 개인 설정과 Drawer에 반영한다. 저장 실패 시 입력은 유지한다. 응답 유실 시에는 실제 저장되었을 수 있으므로 다시 조회한 뒤 판단한다.
- 계정 전환 뒤 늦게 도착한 응답은 반영하지 않는다.

MySQL 스키마·환경 설정 변경은 없다. 서버 재시작 후 개인 설정 → 프로필 수정 → 이름·전화번호 변경 → 저장으로 확인한다. DB와 Drawer에서 변경 내용을 확인하고 앱 재실행 후에도 유지되는지 확인한다.

다크 모드·언어·글씨 크기는 이번 변경에 포함하지 않는다.
