# 가족 공간 탈퇴·강퇴

## 규칙

- 공간 설정의 `공간에서 나가기`: 현재 참여 중인 일반 가족 본인만 탈퇴한다. 계정 탈퇴·공간 삭제와 다르다.
- `함께하는 가족`의 `강퇴`: 현재 주보호자만 같은 공간의 일반 가족을 종료시킨다. 본인·주보호자·다른 공간 또는 이미 종료된 참여는 처리하지 않는다.
- 주보호자는 이전 후 탈퇴해야 한다. 주보호자 이전 기능은 이번 범위에 포함하지 않는다.
- 참여 행을 삭제하지 않고 `participate.left_at=CURRENT_TIMESTAMP`만 기록한다. `is_active`는 `left_at`이 NULL이면 1, 종료 시 NULL로 자동 계산되는 생성 컬럼이므로 직접 UPDATE하지 않는다. DB 테이블·컬럼 변경은 없다. 현재 스키마에는 탈퇴/강퇴 사유·처리자 전용 컬럼이 없어 두 사유의 별도 영구 감사 기록은 추가하지 않았다.
- 메모·채팅·투약 및 완료 일정은 보존한다. 해당 공간의 미완료·미삭제 일정 중 종료 대상자가 맡은 배정만 해제한다. 최신 날짜·시간·내용을 복사한 담당자 없는 새 변경 이력을 남겨 재수락 대기도 종료한다. 다른 공간·다른 가족의 배정은 유지한다.
- 기존 72시간 worker는 이후 검사에서 현재 미배정 상태를 확인한다. 이번 작업은 별도의 탈퇴·강퇴 푸시나 재모집 알림 유형을 추가하지 않는다.

## API

- `POST /family-room/{family_room_id}/leave`
- `POST /family-room/{family_room_id}/members/{participate_seq}/remove`
- Firebase ID 토큰 필요, 본문 없음. 강퇴 대상은 가족 목록의 `participate_seq`다. 사용자·역할은 서버 DB에서 확인한다.
- 성공: `result`, `family_room_id`, `user_id`, `participate_seq`, `released_schedules`.
- 403: 참여·권한 없음. 404: 공간 없음/삭제. 409: 주보호자 탈퇴, 본인·주보호자 강퇴, 이미 종료된 대상. 503: DB 처리 실패.
- 잠금 순서는 공간 → 참여 → 일정/변경 이력. 참여 종료와 배정 해제를 한 트랜잭션으로 확정하며 실패하면 rollback한다.
- 이미 탈퇴한 사용자의 재요청은 403, 이미 강퇴된 대상은 409다. 통신 시간 초과 시 앱은 성공으로 가정하지 않으며 목록 새로고침으로 확인한다.

## 접근 차단·앱 동작

- 기존 각 기능의 `left_at IS NULL` 참여 검사로 기록 조회·알림 조회·푸시 발송 접근을 차단한다. 기기 푸시 등록은 다른 공간에서도 사용하므로 삭제하지 않는다.
- 이 API 프로세스에 연결된 대상 사용자의 채팅 기기만 즉시 4403으로 종료한다. 다른 가족 연결은 유지한다.
- 여러 팀원이 별도 API 서버를 사용하는 개발 환경에서는 연결 목록이 프로세스별이다. 다른 서버의 채팅 연결은 메시지 전달 전/기존 최대 30초 권한 검사에서 차단된다. 서버 간 즉시 종료 신호는 이번에 추가하지 않았다.
- 기존 화면에 이미 받은 데이터는 서버 종료와 동시에 원격 삭제되지 않는다. 강퇴 대상 앱은 재조회·기능 요청·채팅 권한 검사 시 종료 사실을 확인한다.
- 탈퇴 성공 시 해당 공간을 로컬 선택에서 제거하고 공간 목록으로 복귀한다. 강퇴 성공 시 가족 목록을 재조회한다. 확인창에서 영향 범위를 안내하고, 처리 중 중복 제출·취소를 막는다.

## 검증

- `python -m unittest python.tests.test_family_membership python.tests.test_family_room_delete`
- `flutter test test/family_membership_test.dart test/space_settings_test.dart test/family_room_delete_test.dart`
- 테스트는 모의 DB·HTTP·소켓으로 실행한다. 실제 가족 참여나 일정 데이터를 테스트 목적으로 변경하지 않는다.
- 실제 확인: 일반 가족 탈퇴 → 목록에서 해당 공간 제외 → 기존 API 접근 거절. 주보호자 강퇴 → 가족 목록 제외 → 대상 채팅 종료 → 맡은 미완료 일정이 담당자 없는 상태인지 확인. 완료 기록과 다른 공간 배정은 유지되는지 확인한다.
