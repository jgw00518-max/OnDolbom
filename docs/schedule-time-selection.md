# 일정 등록·수정 시간 선택

2026-10-29 사용자 선택 3안의 시·분 독립 휠을 적용했다. 기존 00:00~23:55 통합 드롭다운을 아래에서 열리는 선택창으로 교체한다.

- 시는 00~23, 분은 5분 단위. 기존 일정의 5분 단위가 아닌 값은 임의로 반올림하지 않고 유지한다.
- 취소·바깥 영역 닫기는 원래 값을 유지하고 시간 적용을 눌러야 입력값을 반영한다.
- 종료시간 선택창은 시작시간 기준 +2시간/+4시간/+8시간 빠른 설정을 제공한다. 같은 날짜를 넘기는 옵션은 비활성화한다.
- 기존 시작<종료 검증·신규 등록·편집 API·DB 계약은 유지한다.
- 파일: lib/view/schedules/schedule_create.dart, lib/view/schedules/schedule_time_wheel.dart.
- 자동 검증: 새 시간 선택 4개 및 기존 일정 목록/등록 이동 7개, 총 11개 통과. Flutter 분석 통과. 실제 앱 디자인과 스크롤 체감은 사용자 확인이 필요하다.
