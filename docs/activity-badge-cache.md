# 배지 조회 절감

- `/activity/badges`는 인증과 현재 MySQL 계정 확인 후 Firebase UID별 결과를 60초 캐시한다.
- FastAPI 프로세스 메모리만 사용하며 최대 512개 계정을 보관한다. 재시작 시 사라지고 다른 서버와 공유하지 않는다.
- 부분 장애 결과는 저장하지 않으며 기존 앱의 숫자를 유지한다. 동시 요청은 같은 계정의 계산이 끝난 결과를 재사용한다.
- `?force=true`는 캐시를 우회한다. 푸시 수신·앱 복귀·메뉴 기능 화면에서 복귀·알림 수동 새로고침에 사용한다.
- 공지·문의·알림 읽음 성공 후 현재 서버의 해당 계정 캐시를 폐기한다. 다른 서버에서 바뀐 값은 캐시 만료나 강제 조회로 반영한다.
- Drawer 열기는 일반 조회로 캐시를 활용하고, 정기 갱신은 앱 사용 중 5분 간격으로 유지한다.
- 푸시 큐 5초 검사 및 72시간 재알림 검사는 이번 변경 범위가 아니다. 전체 읽기량에는 이 작업도 포함된다.
- 권한 판정·수락 같은 실제 작업에는 캐시를 사용하지 않는다. 캐시는 메뉴 표시 숫자에만 적용한다.
