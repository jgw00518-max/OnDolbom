# 투약 기간 등록과 남은 날짜 삭제

## DB 적용

`python/features/medications/period_schema.sql`을 한 번 적용한다. nullable 묶음 ID와 인덱스만 추가하며 기존 내용은 변경하지 않는다. 기존 날짜별 기록은 묶음 ID가 없으므로 같은 이름이어도 임의로 연결하지 않는다.

## 동작

- 선택한 날짜를 시작일로 포함해 2·3·5·7·30·90일을 등록한다. 한 달은 30일, 세 달은 90일이다.
- 직접 입력 라디오 선택 시에만 일수 입력이 활성화되고 드롭다운은 비활성화된다. 1~365 정수만 허용한다.
- 요청 `duration_days`를 생략한 기존 API 사용자는 종전처럼 하루만 등록한다.
- 날짜별 체크는 독립적이다. 기간 전체 INSERT는 한 트랜잭션으로 처리한다.
- 삭제는 현재 주보호자만 가능하며 같은 등록 묶음의 서버 날짜 기준 오늘 이후를 삭제 처리한다. 오늘 체크한 항목도 조회에서 제외한다. 과거 기록과 다른 묶음은 유지한다.
- 기존 단일 기록은 해당 기록 하나에만 삭제 기준을 적용한다. 이미 과거라면 삭제 건수는 0일 수 있다.
- 기존 수정 기능은 선택한 날짜의 기록만 수정하며 기간 전체 수정으로 확대하지 않는다.
- MySQL `CURRENT_DATE`가 한국 날짜를 나타내도록 서버 시간대를 맞춘다.
- 삭제는 기존 조회 정책에 맞춰 `record_deleted_at`을 기록하는 방식이다. 기존 복용 이력을 물리 삭제하지 않는다.
