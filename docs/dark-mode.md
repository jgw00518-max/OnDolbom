# 다크 모드

## 사용
- 개인 설정 → 다크 모드 토글에서 즉시 변경한다. 로그인 화면·열려 있는 화면·팝업에도 같은 모드를 사용한다.
- 기기별 appearance.dark_mode 값으로 저장하며 로그인·로그아웃과 분리한다. 처음 설치하면 기존 밝은 모드로 시작한다.
- 실행 전에 저장한 모드를 읽어 밝은 화면이 먼저 보이지 않도록 한다. 저장 실패 시 기존 모드와 안내 메시지를 유지한다.
- 시스템 모드 자동 선택은 제공하지 않는다. 사용자 선택으로 켜고 끈다.

## 색상과 화면
| 역할 | 다크 색상 |
|---|---|
| 배경 | #1E1B19 |
| 카드·입력창 | #292522 |
| 주요 글자 | #F2E9E3 |
| 보조 글자 | #BCAFA5 |
| 살구색 강조 버튼 | #F6B08A (진한 글자) |
| 살구색 면 | #523B2D / #382B24 |
| 세이지색 면 / 강조 | #303C2B / #B7C8A1 |
| 테두리 | #51453E |

- AppTheme에서 공통 테마, AppColors.of(context)에서 역할별 색상을 가져온다.
- 기존 화면의 별도 보조 색상은 AppColors.resolve(context, color)로 통일한다. 화면 전역 변수로 밝기를 저장하지 않으므로 팝업·중첩 Theme도 올바른 값을 사용한다.
- 밝은 모드의 기존 색상은 보존한다. 사진·소셜 로그인 이미지·장식 일러스트 원본을 반전하지 않는다.
- 밝은 강조 버튼 위에는 어두운 글자를 유지한다. 다크 모드 주요 본문 대비는 7:1, 보조 본문은 4.5:1 이상으로 검증한다.
- 새 UI는 const 밝은 색상을 직접 지정하기보다 AppColors.of(context)나 Theme.of(context).colorScheme을 우선 사용한다.

## 검증 범위
설정 저장·복원·실패·전역 전환·열린 팝업·로그인 화면 및 관련 화면 테스트로 확인한다. DB·API·인증·푸시 정책 변경은 없다.
